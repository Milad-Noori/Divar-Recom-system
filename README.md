# :house: House Price Recommendation System (Divar-like)

A machine learning-based system for predicting and recommending house prices, inspired by platforms like Divar.  
Built with Python and Scikit-learn.

---

## :rocket: Features

- :mag: Accurate house price prediction using ML models  
- :bar_chart: Data preprocessing & feature engineering pipeline  
- 🤖 Recommendation system for similar listings  
- :whale: Dockerized for reproducible environments  
- :zap: Fast and lightweight  

---

## 🧠 Tech Stack

- Python  
- Scikit-learn  
- Pandas / NumPy
